# SIGGRAPH 2026 Reference Papers

Local copies of the ten NVIDIA-affiliated papers prioritized for the Prana yoga-teacher project. The PDFs are preserved unchanged from their public sources for development reference.

Downloaded: 2026-07-23

## Motion intelligence

1. [Large-Scale Generative Pretraining for Transferable Motor Control (GPC)](motion/gpc-large-scale-generative-pretraining.pdf)
   - Source: https://arxiv.org/abs/2606.29148
   - Project: https://yi-shi94.github.io/gpc-page/
   - Related code: https://github.com/NVlabs/ProtoMotions (not confirmed as the official GPC release)
2. [MotionBricks: Scalable Real-Time Motions with Modular Latent Generative Model and Smart Primitives](motion/motionbricks.pdf)
   - Source: https://research.nvidia.com/labs/gear/motionbricks/pdfs/motionbricks_siggraph_2026.pdf
   - Project: https://nvlabs.github.io/motionbricks/
   - Preview code: https://github.com/NVlabs/GR00T-WholeBodyControl/tree/main/motionbricks
3. [ARDY: Autoregressive Diffusion with Hybrid Representation for Interactive Human Motion Generation](motion/ardy.pdf)
   - Source: https://research.nvidia.com/labs/sil/projects/ardy/assets/ardy_paper.pdf
   - Project: https://research.nvidia.com/labs/sil/projects/ardy/
   - Code: https://github.com/nv-tlabs/ardy
   - Models: https://huggingface.co/papers/2607.08741
